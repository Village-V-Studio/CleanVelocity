# Security Policy

CleanVelocity is a fork of [PaperMC/Velocity](https://github.com/PaperMC/Velocity) maintained by Village V Studio.

## Supported Versions

Only the latest release (and the current `main` branch) is supported. Security fixes, including fixes for proxy
crashes and other exploits, are released for the latest version only.

## Reporting a Vulnerability

### Regular bugs

For any issues that are **not** security vulnerabilities, crashes triggerable by remote players, or other serious
exploits, please open an issue through the
[Issues tab](https://github.com/Village-V-Studio/CleanVelocity/issues).

### Security vulnerabilities and exploits

**Please do not report security issues in public issues, discussions, or pull requests.**

Use GitHub's private vulnerability reporting instead:

1. Go to the [Security tab](https://github.com/Village-V-Studio/CleanVelocity/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, affected versions, and steps to reproduce (a proof of concept is very helpful).

We will try to acknowledge your report within a few days, keep you updated on progress, and credit you in the
release notes once a fix is published, unless you prefer to stay anonymous.

### Issues in upstream Velocity

If the vulnerability also affects upstream Velocity (not just this fork), please also report it to the PaperMC team
through their [security policy](https://github.com/PaperMC/Velocity/security/policy) so that it can be
fixed at the source.
